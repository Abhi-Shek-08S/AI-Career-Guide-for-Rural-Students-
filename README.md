# CareerPath India — AI-Powered Career Guidance Platform

CareerPath India is a full-stack mobile application that provides **AI-powered, personalised career guidance** to Indian students — especially those from rural, semi-urban, and economically weaker backgrounds. By collecting a student's academic profile, interests, location, and financial situation, the platform uses a Large Language Model (LLM) to generate tailored career paths, college recommendations, scholarship matches, job opportunities, and step-by-step roadmaps.

## Project Overview

Many Indian students lack access to reliable career counselling. CareerPath India bridges that gap by:

- Accepting a detailed student profile via a guided 4-step mobile form.
- Sending the profile to an AI backend that returns ranked **career paths**, **colleges**, **jobs**, **entrance exams**, and **scholarships**.
- Displaying actionable, phase-wise **roadmaps** so students know exactly what to do next.
- Maintaining a curated, offline-first **college and scholarship database** covering 2025 data.

- All API routes are namespaced under `/api`.
- JWT tokens are issued on login/register and are valid for **7 days**.
- LLM calls are handled through the `emergentintegrations` library (`LlmChat`).

## Features

### Student Profile Intake
- 4-step wizard covering: identity, academics, interests, and financial/access situation.
- Captures education level (12th, Graduate, Post-Graduate), stream, marks, subjects, interests, state/district, family income bracket, education budget, and internet access.
- Supports 15+ Indian regional languages.

### AI Career Recommendations
- Sends profile to LLM to generate ranked career paths with feasibility scores (1–10).
- Each career path includes: description, estimated cost, time-to-achieve, key skills, and recommended colleges.

### College Recommendations
- Curated database of government and private colleges across engineering, medical, teaching, nursing, pharmacy, agriculture, computer science, and commerce.
- Each college entry includes: name, location, type, annual fees, course offered, entrance exam, NIRF rank, cutoff, placements, hostel details, scholarships, and campus image.
- Batch image fetching for college thumbnails.

### Jobs by Education Level
- Recommends jobs filtered by the student's completed education.
- Job entries cover: title, description, education required, salary range, sector (Government / Private / Self-Employed), growth potential, key skills, and exam (if applicable).

### Entrance Exam Guide
- Per-college exam guide generated by LLM covering syllabus, preparation tips, and timelines.

### Scholarships
- Real 2025 scholarships matched against student profile keywords.
- Covers NSP (Pre/Post-Matric), PM Scholarship, INSPIRE (DST), AICTE Pragati/Saksham/Swanath, SBI Asha, Reliance Foundation, Tata Capital Pankh, state-specific, UGC, Central Sector, and more.
- Each entry includes provider, amount, eligibility, deadline, and application link.

### Roadmaps
- Phase-wise career roadmap generated by LLM (e.g., 0–3 months, 3–6 months, 6–12 months).
- Each phase lists actions, resources, and milestones.
- Separate job-focused roadmap endpoint.

### User Authentication
- Email/password registration and login.
- Passwords hashed with bcrypt.
- Stateless JWT (HS256) with 7-day expiry.

### Feedback System
- Users can rate recommendations (1–5), mark as helpful, and leave comments.
- Feedback stored per recommendation in MongoDB.

## Backend — API Reference

Base URL: `http://<host>:<port>/api`

| Method | Endpoint                                  | Auth Required | Description                                      |
|--------|-------------------------------------------|:-------------:|--------------------------------------------------|
| GET    | `/`                                       | No            | Health check                                     |
| POST   | `/auth/register`                          | No            | Register a new user, returns JWT token           |
| POST   | `/auth/login`                             | No            | Login, returns JWT token                         |
| GET    | `/auth/me`                                | Yes           | Get current authenticated user info             |
| POST   | `/generate-career-recommendations`        | No            | Generate full career recommendations via LLM    |
| GET    | `/recommendations`                        | Yes           | List saved recommendations for current user     |
| GET    | `/recommendations/{recommendation_id}`   | No            | Get a specific recommendation by ID             |
| POST   | `/generate-roadmap/{career_name}`         | No            | Generate phase-wise roadmap for a career        |
| POST   | `/job-roadmap`                            | No            | Generate a job-focused roadmap                  |
| POST   | `/job-by-education`                       | No            | Get job recommendations by education level      |
| POST   | `/college-exam-guide`                     | No            | Get LLM-generated exam guide for a college      |
| POST   | `/college-campus-images`                  | No            | Fetch campus images for a list of colleges      |
| GET    | `/campus-img`                             | No            | Proxy/fetch a single campus image URL           |
| POST   | `/college-thumbs-batch`                   | No            | Batch-fetch college thumbnail images            |
| POST   | `/feedback`                               | Yes           | Submit feedback for a recommendation            |
| GET    | `/feedback/{recommendation_id}`           | Yes           | Retrieve feedback for a recommendation          |

### Example: Generate Career Recommendations

**POST** `/api/generate-career-recommendations`

Request body (`StudentProfile`):
```json
{
  "name": "Priya Sharma",
  "education_level": "12th",
  "stream": "Science (PCB)",
  "marks_percentage": 82.5,
  "subjects": ["Biology", "Chemistry", "Physics"],
  "interests": ["Healthcare", "Helping others"],
  "location": "Bihar",
  "family_income": "1-3L",
  "budget_for_education": "50k-1L",
  "internet_access": "Limited",
  "language_preference": "Hindi"
}
```

Response includes: `career_paths`, `jobs`, `roadmap`, `scholarships`, `entrance_exams`, `top_colleges`.

## Authentication

- **Algorithm**: HS256 (JWT via `python-jose`)
- **Token expiry**: 7 days
- **Password hashing**: bcrypt via `passlib`
- Protected routes require the header: `Authorization: Bearer <token>`
- The `GET /api/auth/me` endpoint returns the currently authenticated user's `id` and `email`.

## Getting Started

### Backend

```bash
# 1. Create and activate a virtual environment
cd new-project-main/backend
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure environment variables
cp .env.example .env            # then fill in values

# 4. Start the server
uvicorn server:app --host 0.0.0.0 --port 8000 --reload
```

API docs will be available at `http://localhost:8000/docs`.

### Frontend

```bash
cd new-project-main/frontend

# 1. Install dependencies
npm install          # or: yarn install

# 2. Start the Expo dev server
npx expo start

# Then press:
#   a  →  Android emulator
#   i  →  iOS simulator
#   w  →  web browser
#   scan QR code in Expo Go app for physical device
```

## Developer Notes & Optimizations

- **AI Generation Tuning**: The LLM prompt generating recommendations was optimized to request exactly 12 diverse jobs (previously 60/20) and 15 recommended colleges per interest (previously 60). This drastically lowered generation time and HTTP payload, bringing API load times down from ~30s to ~2.5s.
- **Asynchronous Database Writes**: Career recommendation database inserts are now completely decoupled via `asyncio.create_task()` to prevent write blockers from delaying the AI response to the frontend client. 
- **MongoDB Timeout Handling**: To prevent severe latency when the local/remote MongoDB server is spinning up or offline, the `AsyncIOMotorClient` implements a strict connection timeout (`serverSelectionTimeoutMS=2000`).
- **Frontend Changes**: Enhanced user experience by explicitly saying `"Analyzing Profile..."` on the `ProfileFormScreen` loader and refined UI text to be clearer, specifically in the `CareerResultsScreen` ("More colleges on your interest").
